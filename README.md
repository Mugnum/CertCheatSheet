## CertCheatSheet
Визуальное отображение для шпаргалки с вопросами.

### Установка
- Скачать [последний релиз](https://github.com/Mugnum/CertCheatSheet/releases) и распаковать содержимое архива.
- Добавить файл answers.txt, содержащий ответы, рядом с исполняемым файлом. Путь к актуальному файлу можно указать в appsettings.json.
- Запустить CertCheatSheet.exe, автоматически откроется браузер с ответами.
